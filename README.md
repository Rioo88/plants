

# **Planto 🌱**

An iOS app that reminds you to water your plants and tracks your daily progress. Built at the Apple Developer Academy.

## **Features**

- Add, edit and delete plant reminders (room, light, watering days, water amount)
- Mark plants as watered with an animated progress bar
- "All Done!" screen when every plant is watered
- Local notifications based on each plant's schedule
- Data saved between launches, with a daily reset
- Dark design with an Icon Composer app icon

## **Tech Stack**

Swift · SwiftUI · MVVM · `@Observable` · UserDefaults + Codable · UserNotifications · Icon Composer
